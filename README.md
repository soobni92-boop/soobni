# 숩니찡 · NOIR SALON

## 폴더

```
index.html            메인
style.css             전 페이지 공통 스타일
site.js               공통 동작
supabase.js           DB 연결 (프로젝트 바꿀 때 상단 두 줄만 교체)
fx.js                 연출
supabase_setup.sql    테이블 생성 + 접근 권한
assets/               커버 사진, 마스코트
profile/ schedule/ notice/ work/ diary/ dress/
admin/                관리자
.github/workflows/    Supabase 절전 방지 (월·목)
```

---

## 배포 순서

1. GitHub에 이 폴더 그대로 업로드
2. Cloudflare Pages → Connect to Git → 빌드 설정 비움(Framework = None) → Deploy
3. Supabase → Authentication → Users → Add user (이메일·비밀번호, **Auto Confirm User 켜기**)
4. Supabase → SQL Editor → `supabase_setup.sql` 실행
5. `배포주소/admin/` 에서 3번 계정으로 로그인

> 3번을 건너뛰고 4번부터 하면 쓰기 권한이 잠겨 본인도 저장할 수 없습니다.

재배포는 파일 덮어쓰기 후 Commit. 화면이 그대로면 Ctrl + Shift + R.

> 4번을 하기 전까지는 누구나 데이터를 지우거나 고칠 수 있고, 받은 문의도 읽을 수 있습니다.

## 로그인

관리자 비밀번호는 파일 어디에도 없습니다. Supabase에 등록한 계정으로만 들어갑니다.

| | |
|---|---|
| 비밀번호 변경·분실 | Supabase → Authentication → Users |
| 관리자 추가 | 같은 화면에서 계정 추가 |
| 관리자 제외 | 그 계정만 삭제 |

`supabase_setup.sql` 적용 후 권한:

| 동작 | 누가 |
|---|---|
| 사이트 열람 | 누구나 |
| 등록·수정·삭제 | 로그인한 관리자만 |
| 일기 한마디, 문의 보내기 | 누구나 |
| 받은 문의 열람 | 관리자만 |

| 탭 | 내용 |
|---|---|
| 메인 | SOOP 아이디, 프사, 커버 사진·문구, 주간 일정, 방송 요일, 링크, 푸터 |
| 프로필 | 신상, 소개, 어록, 좋아함/싫어함, TMI, 태그, 능력치, 마일스톤, 다시보기 |

| 업보 | 시청자, 업보 종류, 시청자별 횟수 |
| 일기 | 등록·삭제, 기분, 이미지, 달린 한마디 관리 |
| 옷장 | 등록, 분류, NEW ↔ ARCHIVE 전환 |
| 문의함 | 받은 문의 열람·삭제 |
| 문구 | 화면 고정 문구 46개. 검색으로 찾아 수정 |
| 테마 | 색 6종 + 프리셋 5종 + 대비 진단 + 글자 크기 4단 배율 |

메인·프로필·테마는 저장 버튼 하나로 함께 저장됩니다.

### 상단 도구
백업(.json) · 복원 · 이 탭 페이지 보기 · 저장 안 한 변경이 있으면 상단에 표시됩니다.

### 자동 계산
- 생일 D-Day ← 프로필 탭 `생일`
- 경과일(DAY n) ← 프로필 탭 `데뷔일`
- 다음 방송 ← `다음 방송 내용`을 비우면 방송 요일 체크로 계산
- 프로필 사진 ← SOOP 아이디 (직접 URL 입력 시 그쪽 우선)

### 형식이 있는 칸
| 칸 | 형식 | 예 |
|---|---|---|
| 능력치 | `이름:숫자` (0~100) | `입담:92` |
| 마일스톤 | `상태\|내용` | `진행중\|찡구 1,000명` |
| 어록 | 한 줄에 하나 | |
| 태그 | 쉼표 구분 | |
| 이미지 | 한 줄에 하나 | |

## 이미지

파일을 올리지 않고 주소만 씁니다.

1. SOOP 비공개 게시판에 업로드
2. 이미지 우클릭 → 이미지 주소 복사
3. 관리자 이미지 칸에 붙여넣기

글 주소가 아니라 `stimg.sooplive.com` 으로 시작하는 직접 주소여야 합니다. 원본 글을 지우면 사이트 이미지도 깨집니다.

권장 비율 — 옷장 세로 3:4(900×1200) / 커버 가로 16:9 / 마스코트 투명 PNG

## SOOP 게시글 삽입

```html
<iframe height="2000" scrolling="no" src="배포주소/profile/" style="width:100%;border:0;display:block;"></iframe>
```

높이는 % 가 아니라 픽셀로 지정합니다.

| 페이지 | 시작 높이 | 증가 |
|---|---|---|
| 메인 | 900 | - |
| 프로필 | 4200 | - |
| 일정 | 2000 | - |
| 공지 | 1100 | 1건당 +60 |
| 업보 | 1100 | 5명당 +180 |
| 일기 | 1100 | 1편당 +60 |
| 옷장 | 1500 | 3개당 +380 |

## 참고

- 낮/밤 전환은 브라우저에 저장되어 페이지를 옮겨도 유지됩니다.
- 옷장 `새 옷으로 올리기` 체크 = 포스터, 해제 = 아카이브. 표에서 전환 가능합니다.
- 일정에 종료 날짜를 넣으면 달력에 시작일부터 종료일까지 띠로 이어집니다.
- 일정 구분을 `휴방`으로 하면 CLOSED로 표시됩니다.
- 모든 모달은 ESC로 닫힙니다.
- 마스코트 이미지를 바꾸면 커버·페이지 제목 옆·로딩화면이 함께 바뀝니다.
- 절전 방지를 쓰려면 GitHub → Settings → Secrets 에 `SUPABASE_URL`, `SUPABASE_ANON` 등록.
