**① Supabase 연결** — ✅ **이미 넣어놨습니다.** (`supabase.js` 맨 위 두 줄)

```js
const SUPABASE_URL  = 'https://nmjcqzfcejxkaczmfink.supabase.co';
const SUPABASE_ANON = 'eyJhbGciOi...'  // anon public 키
```

나중에 Supabase 프로젝트를 새로 만들면 이 두 줄만 바꾸면 됩니다.

**② SQL 실행** — Supabase → SQL Editor → `supabase_setup.sql` 전체 붙여넣고 Run
(여러 번 실행해도 안전합니다. 기존 데이터를 지우지 않습니다.)

**③ 관리자 비밀번호 변경** — `admin/index.html` 안에서

```js
var PW = '1234';   /* ⚠ 배포 전에 반드시 바꾸세요 */
```

지금은 임시로 `1234` 입니다. **꼭 바꾸고 올리세요.**
(소스에 그대로 보이므로 다른 곳에서 쓰지 않는 “버리는 비밀번호”로 정해 주세요.)

> 배포: GitHub에 이 폴더 구조 그대로 올리고 → Cloudflare Pages → Connect to Git → 빌드 설정 비움(Framework = None) → Deploy.

**메인 · 프로필 · 테마는 저장 버튼 하나로 함께 저장됩니다.**
저장 → 사이트 새로고침 → 반영됩니다.

### 자동으로 계산되는 것
- **생일 D-Day** — 프로필 탭 `생일`(MM-DD)에서
- **방송 며칠째(DAY n)** — 프로필 탭 `데뷔일`(YYYY-MM-DD)에서
- **NEXT TRANSMISSION** — “다음 방송 내용”을 비워두면 방송 요일 체크를 보고 자동 계산
- **프로필 사진** — SOOP 아이디만 넣으면 자동. 직접 URL을 넣으면 그쪽이 우선

### 형식이 정해진 칸
| 칸 | 형식 | 예 |
|---|---|---|
| 능력치 | 한 줄에 `이름:숫자`(0~100) | `입담:92` |
| 마일스톤 | 한 줄에 `상태\|내용` | `진행중\|찡구 1,000명` |
| 어록 | 한 줄에 하나 | `아무래도~` |
| 특징 태그 | 쉼표로 구분 | `하트, 달/밤하늘, 악마날개` |
| 이미지 주소 | 한 줄에 하나 | `https://stimg.sooplive.com/...` |

## 4. 이미지 넣는 법

이미지는 서버에 올리지 않고 **주소(링크)만** 씁니다.

1. SOOP 비공개 게시판에 이미지를 올린다
2. 그 이미지를 **우클릭 → 이미지 주소 복사**
3. 관리자 이미지 칸에 붙여넣는다

> ⚠ 글 주소가 아니라 `https://stimg.sooplive.com/…` 처럼 **이미지 파일 직접 주소**여야 합니다.
> ⚠ 원본 글을 지우면 사이트 이미지도 같이 깨집니다.

**권장 비율** — 옷장: 세로 3:4 (900×1200) / 커버 배경: 가로 16:9 / 마스코트: 배경 뚫린 투명 PNG

## 6. 사람이 놓치기 쉬운 것

- **낮/밤 전환**은 브라우저에 기억되어 페이지를 옮겨도 유지됩니다.
- **문의**는 사이트 어느 페이지에서나 우측 상단 `✉ SEND` → 관리자 ✉ 문의함에 쌓입니다.
- **옷장 “새 옷으로 올리기”** 체크 = NEW LOOKS 포스터 벽, 해제 = ARCHIVE 그리드. 표에서 언제든 전환됩니다.
- **일정 “휴방”** 을 고르면 페이지에 `CLOSED` 로 표시됩니다.
- **마스코트 이미지**를 관리자에서 바꾸면 커버·각 페이지 제목 옆·페이지 전환 로딩화면이 한 번에 바뀝니다.
- **keepalive** 를 쓰려면 GitHub 저장소 Settings → Secrets 에 `SUPABASE_URL`, `SUPABASE_ANON` 두 개를 등록하세요.
